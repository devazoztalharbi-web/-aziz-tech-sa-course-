# Episode 0.4 examples — task organizer (lists, loops, functions, dicts, strings)

Windows PowerShell (recommended launcher):

```text
py --version
py 01_list_tasks.py
py 14_task_manager.py
```

If `py` is missing but Python is on PATH, try `python` instead.
On Linux/macOS verification we use `python3`.

Deliberate error demos (expected to fail):

- `04_bug_indent.py` -> IndentationError
- `11_bug_keyerror.py` -> KeyError: 'name'

Main project: `14_task_manager.py`
