# فيديو الحلقة 0.2

الحلقة محفوظة داخل أرشيف `7z` باسم `episode02.7z` وأجزائه المرقمة، بدون تقليل جودة الفيديو. أبق جميع الأجزاء في مجلد واحد، ثم افتح `episode02.7z.001` بواسطة 7-Zip على ويندوز أو Keka على ماك واستخرج الفيديو.

على Linux مع برنامج 7-Zip:

```
cd video
7z x episode02.7z.001
sha256sum -c SOURCE_SHA256.txt
```

النتيجة `episode02.mp4` لرفعها على يوتيوب؛ لا ترفع ملفات 7z نفسها إلى يوتيوب. إذا ظهرت رسالة فتح الأرشيف، تأكد أنك نزلت جميع الأجزاء بما فيها الجزء الأخير قبل فتحه. مقارنة البصمة في الملف المرفق يجب أن تعطي OK.

رابط نشر الحلقة غير مسجل هنا حتى الآن، ويسجل بعد النشر في `../youtube/VIDEO_URL.txt`.
