# أمثلة الحلقة 0.5 — دفتر الملاحظات (قراءة وكتابة الملفات)

شغّل كل ملف من PowerShell داخل مجلد الحلقة: `py filename.py`

| الملف | وش يسوي |
|---|---|
| 01_forgets.py | البرنامج ينسى كل شي إذا قفل (ليش نحتاج ملفات) |
| 02_write_first_note.py | أول كتابة في ملف بالوضع "w" |
| 03_read_notes.py | قراءة الملف بالوضع "r" |
| 04_mistake_wrong_name.py | خطأ متعمد: FileNotFoundError (اسم الملف غلط) |
| 05_w_starts_fresh.py | "w" يمسح القديم ويبدأ من جديد |
| 06_a_adds_line.py | "a" يضيف في السطر اللي بعده |
| 07_mistake_no_newline.py | خطأ متعمد لطيف: نسيان \n فتلتصق الكلمات |
| 08_with_closes_for_you.py | with تقفل الدفتر عنك تلقائيًا |
| 09_notebook.py | المشروع: دفتر ملاحظاتي |
| 10_exercise_solution.py | حل التمرين: كم ملاحظة في الدفتر؟ |
| 11_homework_solution.py | حل الواجب: دفتر أسماء + آخر اسم |

ملاحظة: الأمثلة 03 و05 و06 و08 و10 تعتمد على notes.txt من اللي قبلها؛ شغّلها بالترتيب.
تم اختبار كل الأمثلة على Python 3.13.5.
