# الحلقة 0.1 — أساسيات عمل الإنترنت

## الملفات
- `video/`: أرشيف 7z مجزأ للحلقة الكاملة (`episode01.7z.001` …). راجع `video/README.md`.
- `script.md`, `chapters.txt`, `subtitles/episode01.srt`, `thumbnail.png`
- `youtube/title_description.md`, `youtube/VIDEO_URL.txt` (رابط النشر غير مسجل بعد)
- `socials/`: Shorts وTikTok وSnapchat وX وInstagram Reels وLinkedIn وFacebook Reels ونصوص Threads

لا يوجد مجلد examples لهذه الحلقة. دليل المنصات العام في `/PUBLISHING_GUIDE.md`.
