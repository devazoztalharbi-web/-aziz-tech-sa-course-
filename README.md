## الحلقات المجهزة للأرشيف

- [الحلقة 0.1: أساسيات عمل الإنترنت](episodes/ep01/)

الحلقتان 0.2 و0.3 غير مرفقتين في هذا المستودع بعد. لا تُنشأ مجلدات فارغة لهما، ولا تُضاف روابط حلقات قبل توفر ملفاتهما.

كل حلقة لها مجلد مستقل داخل `episodes`. يبقى اسم المجلد ثابتًا حتى لو تطور المحتوى، لتبقى الروابط واضحة وثابتة.

## ما تجده في مجلد الحلقة

- `video/`: الحلقة الأصلية كاملة محفوظة في أرشيف 7z مجزأ بدون تقليل جودتها، مع تعليمات الاستعادة وبصمات التحقق.
- `script.md`: نص الحلقة.
- `chapters.txt`: فصول اليوتيوب.
- `subtitles/`: ملف الترجمة.
- `thumbnail.png`: الصورة المصغرة الجاهزة.
- `youtube/`: العنوان والوصف والوسوم المتوفرة.
- `socials/`: المقاطع والنصوص المخصصة لكل منصة.
- `examples/`: أمثلة الأكواد، عندما تحتوي الحلقة عليها.

الـ GitHub هنا أرشيف ومرجع للقناة والأكواد، وليس بديلًا عن مشاهدة الحلقات على يوتيوب أو نشر المقاطع على المنصات. لا نرفع أجزاء الترجمة الداخلية أو ملفات العمل المؤقتة.

## فك فيديو الحلقة

حافظ على جميع ملفات 7z المرقمة في مجلد واحد. افتح ملف `episode01.7z.001` في 7-Zip على ويندوز أو Keka على ماك، ثم استخرج الفيديو. غيّر رقم الملف للحلقة المطلوبة.

على Linux مع برنامج 7-Zip:

```
cd video
7z x episode01.7z.001
sha256sum -c SOURCE_SHA256.txt
```

يفك ملف MP4 كاملًا مع مطابقة بصمته بالنسخة الأصلية. لا ترفع ملف الأرشيف إلى يوتيوب، بل ملف MP4 الناتج.

## للحلقات الجديدة

أنشئ مجلدًا جديدًا بترقيم متسلسل مثل `episodes/ep04`، ثم استخدم نفس الهيكل. لا تضغط حلقة جديدة فوق مجلد حلقة سابقة.
